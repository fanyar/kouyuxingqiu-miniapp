# 实际读音时间轴方案

这份文档是章节音频、逐句高亮和播放间隔的执行标准。后续所有章节都按本方案处理。

唤醒关键词：

```text
实际读音时间轴方案
```

## 核心原则

时间轴的对象是“实际读音出现次数”，不是“绘本文本句数”。

同一句绘本文字如果音频里读两次，就必须有两条独立的句子记录、两组独立时间轴，并在两次播放时分别高亮。音频里的标题读音、重复朗读、补读都算一次实际读音。非朗读的音乐、环境音和杂音不算句子，也不建句子记录。

A1、A2、B1、B2 已按本方案完成验证：

## 时间轴生成规则

1. 使用课程原声 MP3，不使用 TTS 替代原声。
2. 将 MP3 转成 16kHz mono WAV，仅作为临时识别文件。
3. 按标准片段识别：每段 4 秒，相邻片段重叠 2 秒。
4. 对可疑位置使用 0.5 秒步进的重叠片段复核。
5. 使用本地语音识别输出的词级时间戳对齐绘本文本。
6. 每次实际读音生成一条 `sentences` 记录。
7. 同一句读两遍就建两条记录，ID 必须不同。
8. 开头标题读音也要建记录。
9. `start/end` 只表示该次实际读音边界，不把句间杂音包进去。
10. 不能只靠音量判断正式时间轴。

## 播放规则

### 章节开头

1. 章节打开后从音频 `0s` 播放。
2. 第一句实际读音在 `2s` 内开始：自然等待，不跳转。
3. 第一句实际读音超过 `2s` 才开始：播放到约 `1.8s` 时跳到第一句实际读音，让听感上约 `2s` 开始朗读。

### 句间间隔

1. 自然间隔小于等于 `1.5s`：完全按原音频播放，不跳转、不拉慢。
2. 自然间隔大于 `1.5s`：上一句实际读音结束后保留约 `1s`，再跳到下一句实际读音开始。
3. 句间独立的音乐、环境音和杂音跳过。

### 单句和键盘

1. 点击任意一句，只读这一句，读完自动暂停。
2. 空格键切换播放和暂停。
3. 单句播放中按空格：暂停或继续这一句，读完后仍自动暂停。
4. 整章播放结束后按空格：从章节开头重新播放。

## 高亮规则

1. 每次实际读音独立高亮。
2. 第二遍重复句也必须放大。
3. 高亮在读音开始后出现，避免文字先于声音出现。
4. 读音结束后取消高亮。

## 数据写入规则

1. 每章修改后必须更新 `timingVersion`。
2. 不复用旧 `timingVersion`。
3. 时间保留两位小数。
4. 句子记录必须按音频出现顺序排列。
5. ID 可以不连续，但必须唯一。
6. 不允许时间轴重叠、越界、反向。

## 验收标准

每章至少检查：

1. 所有实际读音都有句子记录。
2. 重复句第二遍能独立高亮。
3. 整章能连续播放到 `ended`。
4. 章节开头符合 2 秒规则。
5. 句间符合 `1.5s / 1s` 规则。
6. 不切掉上一句最后一个单词。
7. 点击单句读完暂停。
8. 空格键播放/暂停正常。
9. `node --check assets/app.js` 通过。
10. `node --check data/chapters.js` 通过。
11. `git diff --check` 通过。
12. 浏览器自动验证和人工试听都通过。

## 推广流程

后续章节按批处理：

1. 先做本地词级识别。
2. 再整理实际读音出现次数和边界。
3. 可疑读音不猜测，必须细粒度复核。
4. 写入 `data/chapters.js` 并更新 `timingVersion`。
5. 完成整章播放、高亮、单句、空格键和间隔验证。
6. 全部章节完成后做一次 52 章总验收。
